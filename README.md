# AstrBot 群聊与私聊自然接话插件

`astrbot_plugin_turn_taking` · v0.7.2

让机器人在被叫到之后自然续聊、适时收尾，并根据具体话题选择稍后再接一句。支持隐藏语音/文字标记、被动的未完话题记录和本地发送状态观察。

## 功能

- **连续对话**：被 @ 或点名后，可接住同一人的后续消息；遇到收尾、超时、他人插话或轮数上限时结束话轮。
- **适度参与**：群聊有条件地按概率参与；私聊沿用原生回复流程，不进行群聊式随机发起。
- **自主接话**：主模型可用 `self_initiative` 工具或 `[[开口:秒数]]` 安排一次稍后重新考虑的机会。到时读取最新上下文，可以说，也可以沉默。
- **回复方式**：最终正文末尾的 `[[语音]]` / `[[文字]]` 只控制当前回复，没有标记时沿用 AstrBot 原有 TTS 概率。标记在发送、语音与记忆正文之前剥离。
- **未完话题**：每个会话最多 2 条，从实际提起或推进后再保留 5 天；只被动接续，不触发主动发言。到期后留下有界清理记录，记录最多 100 条、保留 7 天。
- **发送状态**：区分处理中、准备回复、发送中、接口成功、明确拒绝、部分成功和未确认。失败信号不会被后续成功钩子抹掉。

## 安装与配置

运行接口按 AstrBot v4.29.1 验证。需要配置聊天模型；语音标记还需要在 AstrBot 中启用并配置 TTS 提供商。

1. 在 AstrBot 插件管理中通过此仓库地址安装：
   `https://github.com/971718643/project-1`
2. 或运行 `python build_package.py`，将 `dist/` 下的插件 ZIP 上传到插件管理页面。
3. 在插件配置中调整范围、概率、冷却和主动发言限次；机器人称呼可在 `main.py` 的 `bot_names` 中调整。

配置默认值：

| 设置 | 默认值 |
| --- | --- |
| 群聊范围 | 所有群，不检查白名单 |
| 私聊自主接话 | 开启 |
| 群聊随机参与概率 | 5%，仍需通过上下文与频率检查 |
| 主动发起冷却 | 300 秒 |
| 主动发起上限 | 每会话 3 次/小时、12 次/天 |
| 静默时段 | 北京时间 23:00–08:00 |
| 自主预约延时 | 300–7200 秒 |
| 并发自主会话 | 最多 4 个，同会话串行 |

主动限次约束自主发起；普通被叫到后的回复沿用原有聊天流程。到期选择沉默或生成失败也消耗一次主动尝试，避免无限重试。

## 状态与数据

管理状态接口：`/api/v1/plugins/extensions/astrbot_plugin_turn_taking/status`。模型工具 `self_initiative(action="status")` 只查询当前会话。

发送接口成功不代表对方收到或已读。明确的结构化 OneBot 拒绝才显示接口执行失败；超时或缺少确认显示未确认，不推测平台拦截。复杂转发/文件可能部分发送，因此不将后续失败当作整段都没发送。

普通回复的观察仅在当前进程内保留最近 100 个事件，重启或重载后重新积累；仅记录元数据，不保存正文。自主任务的领取与终态另有持久记录，不会因故障自动补发。未完话题按当前会话、参与者和对话/人格范围过滤。

安装后插件会在 AstrBot 插件数据目录生成任务、近期上下文、次数、结果和未完话题等运行文件。这些文件不属于本仓库内容。仓库只包含实现、合成测试数据和文档。

## 开发与验证

使用 Python 3.12：

```bash
python -X utf8 -m unittest discover -s tests -p "test_*.py"
python -X utf8 build_package.py
```

当前包含 336 项离线测试，覆盖调度并发、原子写盘与故障恢复、跨会话隔离、话题续期、标记解析、语音流程及发送异常。测试不调用模型、不连接 QQ、不发送真实消息。

`tests/fixtures/` 包含离线测试需要的代码参考快照，来源与许可见该目录的 `NOTICE.md`。这些参考文件不进入插件安装包。

源码发布目录已调整为 AstrBot 可直接加载的仓库根目录；功能代码与部署版本 v0.7.2 保持一致，仓库元数据和测试路径作了发布适配。
